# Phase 6 — Hashing

Welcome to **Phase 6**. This phase covers hash functions, collision resolution (chaining vs open addressing), C++ STL containers (`unordered_map`, `unordered_set`, `map`, `set`), frequency counting, Two-Sum / K-Sum hashing patterns, prefix sum + hashing subarray problems, and custom hash functions.
