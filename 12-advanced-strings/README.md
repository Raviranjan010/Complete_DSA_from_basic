# Phase 12 — Advanced Strings

Welcome to **Phase 12**. This phase covers advanced string algorithms: KMP (Knuth-Morris-Pratt) pattern matching with LPS derivation, Z-algorithm, Rabin-Karp rolling hash, Trie applications, Manacher's algorithm for linear palindrome searching, and Suffix Arrays/Trees.
