# Phase 13 — Bit Manipulation & Math for DSA

Welcome to **Phase 13**. This phase covers bitwise representation (two's complement, bit shifts), low-level bit tricks, XOR properties, subset generation via bitmasking, Number Theory (Sieve of Eratosthenes, Euclidean GCD/LCM, modular arithmetic, modular inverse), Combinatorics ($n\text{C}r$), and basic Game Theory (Nim game & Grundy numbers).

---

## 📌 Phase Roadmap & Sub-topics

*(Concept files and practice sets will be generated during Phase 13 execution)*

- **13.1** Binary representation, two's complement, bitwise operators recap (`&`, `|`, `^`, `~`, `<<`, `>>`)
- **13.2** Common bit tricks: check/set/clear/toggle a bit, count set bits, power of two check
- **13.3** XOR tricks: single number problems, swapping without a temp variable
- **13.4** Subsets via bitmasking
- **13.5** Number theory: primes (Sieve of Eratosthenes), GCD/LCM (Euclidean algorithm), modular arithmetic
- **13.6** Modular exponentiation, modular inverse
- **13.7** Combinatorics basics: permutations, combinations, Pascal's triangle, nCr with mod
- **13.8** Basic game theory (Nim game, Grundy numbers)
