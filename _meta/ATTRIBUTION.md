# Attribution & Source Preservation Log (`ATTRIBUTION.md`)

This repository consolidates educational materials, notes, problem sets, and code implementations from five original open-source projects. In compliance with Golden Rule **R12 (Keep Licenses & Attribution)**, full credit is given below to the original authors, educators, and maintainers.

---

## 1. Source Repositories & Authors

### 1.1 `DSA_server-main` (`DSA-MasterCourse`)
- **Title**: *DSA Master Course — From Zero to FAANG*
- **Origin**: Complete C++ Data Structures & Algorithms Course based on Striver (takeUforward) SDE Sheet curriculum and FAANG interview question collections.
- **Contributions Preserved**: 
  - Systematic array taxonomy (Fundamentals, Two Pointer, Sliding Window, Prefix Sum, Kadane, Binary Search).
  - Common mistakes and pattern recognition guides across array algorithms.
  - MCQs and conceptual self-check questionnaires.
  - Interview question sets for 7 major tech companies (Adobe, Amazon, Flipkart, Google, Meta, Microsoft, TCS).

### 1.2 `DSA_ac-main`
- **Title**: *Apna College DSA Course Materials & Deep Notes*
- **Origin**: Apna College C++ Data Structures & Algorithms series.
- **Contributions Preserved**:
  - In-depth, formal mathematical proofs and step-by-step derivations for Time and Space Complexity.
  - C++ pointer fundamentals, memory addressing models (`&`, `*`), and memory layout diagrams.
  - Exemplary walk-throughs of classic problems: Kadane's algorithm, Container With Most Water, Product of Array Except Self, Majority Element (Boyer-Moore Voting), and Binary Search.

### 1.3 `Summer_pep_DSA-main`
- **Title**: *Summer Pep DSA Notes — Built For Beginners (Batch 2026)*
- **Author / Mentor**: Ajai Raj
- **Contributions Preserved**:
  - Beginner-first, empathetic pedagogical explanations designed for first-time programmers.
  - Multi-language comparison guides (`Cpp-Basics.md`, `Java-Basics.md`, `Python-Basics.md`).
  - Clear intuitive introductions to recursion, linked lists, stacks, queues, and sliding windows.

### 1.4 `DSA_final-main`
- **Title**: *DSA Final — Foundations and C++ Core*
- **Author**: Raviranjan (`Raviranjan010/DSA_final`)
- **Contributions Preserved**:
  - Foundations of C++ programming: type casting, control flow, loops, patterns, functions, binary number systems.
  - Pointer arithmetic, pass-by-value vs pass-by-reference demonstrations.
  - Subarray fundamentals and early Kadane implementations.

### 1.5 `dsa-main`
- **Title**: *Student DSA Code Practice & WebAssembly Demo Project*
- **Author**: Raviranjan (`Raviranjan010/dsa`)
- **Contributions Preserved**:
  - 57 compiling C++ problem implementations covering recursion, matrix operations, sorting, prefix sums, and basic algorithms.
  - Emscripten WebAssembly student record project and demonstration files (preserved in `_extras/`).

## 2. Integrity Statement

No content from these repositories has been discarded or destroyed without justification. All code and notes are either:
- **MERGED** into unified canonical topic hubs;
- **MOVED** into standardized language folders (`code/`);
- **ARCHIVED** into `_archive/` for historical reference; or
- **CATEGORIZED AS EXTRA** in `_extras/` for standalone non-DSA projects.
